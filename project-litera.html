LITERAcari & terjemah.

Riset · Web app · Dipakai untuk disertasi doktoral

DIPAKAI DI LAPANGAN

Mencari jurnal di lima sumber akademik sekaligus, menyimpannya ke pustaka, lalu menerjemahkan PDF-nya tanpa merusak rumus dan tabel.

Punya kebutuhan serupa? Chat WA →
JENIS
Web app + REST API
PEMAKAI
Peneliti disertasi (S3)
STACK
Laravel 12 + React
TERJEMAHAN
LibreTranslate / LLM

Masalahnya

Riset disertasi berarti membuka lima situs pencarian jurnal satu per satu, menyalin sitasi secara manual, dan menerjemahkan PDF berbahasa asing yang tata letaknya hancur begitu teksnya disalin.

Cara kerjanya

Satu kueri dijalankan paralel ke OpenAlex, Semantic Scholar, CrossRef, DOAJ, dan Garuda, lalu hasilnya digabung dan duplikatnya dibuang berdasarkan DOI dan judul. Terjemahan berjalan di antrean: mode cepat gratis lewat LibreTranslate, mode akurat lewat LLM dengan kuota bulanan per pengguna.

Dibangun dengan

  • Laravel 12
  • React (Vite)
  • MySQL
  • Sanctum
  • LibreTranslate
  • pdf2zh

Dalam angka

5SUMBER JURNAL
2FORMAT SITASI
2MODE TERJEMAHAN
2BERKAS PER PDF

Fitur utama

  • Pencarian gabungan dengan filter tahun, open access, bahasa, dan sumber
  • Pustaka per pengguna: simpan paper, folder, tag, dan catatan
  • Ekspor sitasi BibTeX dan RIS untuk Mendeley, Zotero, dan Word
  • Riwayat pencarian per pengguna
  • Terjemahan dari teks, abstrak, atau unggahan PDF
  • PDF dwibahasa yang mempertahankan rumus, tabel, dan gambar
  • Multi-pengguna dengan login token
