# Galeri project dipisahkan dari studi kasus

Tangkapan layar dari portfolio lama membuat Project mandiri punya bahan visual, padahal aturan situs ini menyebut halaman cerita (**Studi kasus**) hanya untuk Project yang benar-benar dipakai orang. Daripada melonggarkan aturan itu, kami menambah jenis halaman kedua: **Galeri project** — tangkapan layar dan daftar teknologi saja, tanpa cerita pemakaian, untuk Project mandiri.

## Consequences

- Kartu Project mandiri kini boleh punya gambar sampul dan menaut ke galerinya; kartu tanpa tangkapan layar tetap tanpa area gambar.
- Pembaca tetap bisa membedakan "ada yang memakai ini" dari "saya sudah pernah membangun yang seperti ini" hanya dari jenis halamannya.
- Galeri ditulis sebagai satu halaman per bahasa dengan anchor per project, bukan satu file per project, agar beban perawatan dua bahasa tidak berlipat.
