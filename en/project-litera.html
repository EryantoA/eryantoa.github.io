LITERAsearch & translate.

Research · Web app · Used for doctoral dissertation work

IN USE

Searches five academic sources at once, saves papers to a library, then translates the PDF without breaking its equations and tables.

TYPE
Web app + REST API
USED BY
A doctoral researcher
STACK
Laravel 12 + React
TRANSLATION
LibreTranslate / LLM

The problem

Dissertation research meant opening five journal search sites one by one, copying citations by hand, and translating foreign-language PDFs whose layout fell apart the moment the text was copied out.

How it works

One query runs in parallel against OpenAlex, Semantic Scholar, CrossRef, DOAJ and Garuda; the results are merged and de-duplicated by DOI and title. Translation runs on a queue: a free fast mode through LibreTranslate, and an accurate mode through an LLM with a monthly quota per user.

Built with

  • Laravel 12
  • React (Vite)
  • MySQL
  • Sanctum
  • LibreTranslate
  • pdf2zh

In numbers

5JOURNAL SOURCES
2CITATION FORMATS
2TRANSLATION MODES
2FILES PER PDF

Core features

  • Federated search with year, open-access, language and source filters
  • Per-user library: saved papers, folders, tags and notes
  • BibTeX and RIS citation export for Mendeley, Zotero and Word
  • Per-user search history
  • Translation of plain text, abstracts or uploaded PDFs
  • Bilingual PDFs that keep equations, tables and figures intact
  • Multi-user, with token-based login
