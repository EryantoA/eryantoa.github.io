OPENclaw

AI assistant · WhatsApp + Telegram

PERSONAL USE

A family expense tracker with no app to install — you text it like a person and it files the expense.

Want a WhatsApp bot for your business? Chat →
TYPE
Chat assistant
USED BY
My own family
RUNTIME

DATA
CSV ledger

The idea

Budgeting apps fail because nobody opens them. The cheapest interface a family already uses every day is a chat thread — so the tracker went there instead.

How it stays up

Three model providers behind one gateway: Groq first for speed, DeepSeek when rate limits hit, Claude as last resort. A failing provider is a detour, not an outage.

Built with

  • Node 24
  • OpenClaw
  • Groq
  • DeepSeek
  • Claude
  • CSV

In numbers

3AI PROVIDERS
2CHAT PLATFORMS

Core features

  • Logs expenses from a plain message, no special format
  • WhatsApp and Telegram served from one gateway
  • Falls over to the next AI provider on error or rate limit
  • Remembers categories, accounts and household context
  • Every transaction in one CSV ledger, with backups
  • Runs on my own machine — no subscription per family member
